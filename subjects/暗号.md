# 暗号 — 30問/16分

出典: ユーザー提供のWeb-CAB対策情報(2026-08-22受領)をもとに整理。

## 攻略の考え方

- 元の図形が最終的にどう変化したかを箇条書きにし、複数の図形に共通する変化に着目する。
- 複雑な問題は、通過する暗号(処理)の数が少ない図形から解読を始めると解きやすい。
- 「ある図形に特定の処理を適用すると別の図形になる」という構造を分解して考える能力が問われる。
- 最初の方の問題は難易度が低い傾向があるため、そこでいかに時間を節約できるかが勝負になる。

## パターン分類と解法のコツ(学習者メモ、2026-09-02時点)

出題は大きく「塗り・変形」「回転・移動・増減」「数字・文字」の系統に分かれる。

- **塗り・変形**: 三角→円、円→三角のように図形の種類が変わっても同じ暗号記号になる場合がある。
- **回転・移動・増減**: 「増減」を見落としがち。増減はわかりやすい暗号なので、他の変化を探す前に必ず確認する。
- **数字・文字**: 数字は倍数のパターンもあるため、単純な足し引きだけでなく最終的な着地点(終着点)を考える。ひらがなの問題は比較的易しい。

共通の考え方: 複数の図形に共通している変化点は何かを考える。

**ルール発見**: 黒矢印・白矢印がある場合、同じ色の矢印の方向にしか進めない(色ごとに経路が分かれている)。これを知らないと法則を見誤りやすい。

得意/不得意(2026-09-02時点):
- 得意: ひらがなの問題(易しいので時間をかけてでも解く方針)
- 不得意: 回転・移動・増減で出てくるマス目の問題(難易度が高いため、本番では飛ばす方針)

**時間感覚のメモ**: 大問(2〜3問のまとまり)単位で所要時間を記録すると「1問1〜2分」のように見えて実際より時間がかかっている錯覚が生まれやすい。実際の1問あたりの所要時間は概算で30秒程度であることが多く、演習量を積めば感覚が掴めてくる。

## 例題(簡易・自作)

暗号ルールの例:
```
○(白丸) → 暗号「X」 → ●(黒丸)
□(白四角) → 暗号「X」 → ■(黒四角)
```
問題: 暗号「X」とは何をする暗号か。また、△(白三角)に暗号「X」を適用するとどうなるか。

解答: 暗号「X」は「色を白から黒に反転させる」暗号。△に適用すると▲(黒三角)になる。
