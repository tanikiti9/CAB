# 四則演算(暗算) — 50問/9分

出典: ユーザー提供のWeb-CAB対策情報(2026-08-22受領)をもとに整理。

## 攻略の考え方

- 小数・分数・四則混合の計算を解く。**正確に計算する力より、素早く概算する力**が問われる。時間内に全問を正確に計算しきることはまず不可能。
- 四捨五入・切り上げ・切り捨てで数値を扱いやすい形にしてから概算する(例: 13.46−425−6.85 → 10−430−1＝−421 に最も近い選択肢を選ぶ)。
- 概算結果が本来の計算結果より「大きくなる方向にずれるか/小さくなる方向にずれるか」の傾向も把握しておくと選択肢の絞り込みが安定する。
- 前半は易しく後半ほど難化する傾向があるため、時間配分に注意。
- 1問あたり約11秒しかかけられない計算になる(50問/9分)。

## 例題(簡易・自作)

問題: 次の計算をせよ。
```
7/8 - 0.375 = ?
```
選択肢: A. 0.5  B. 0.425  C. 0.375  D. 0.625

解答: A(7/8=0.875、0.875-0.375=0.5)
