# 命令表 — 36問/15分

出典: ユーザー提供のWeb-CAB対策情報(2026-08-22受領)をもとに整理。

## 攻略の考え方

- 命令を「操作」「参照」「全体」に分類し、現在の状態をメモで固定・更新しながら解く。
- 頭の中だけで処理すると、ミス・参照対象のずれ・処理順の取り違えが起きやすい。図形への番号振り、空白の即時確定、処理順の固定を徹底する。
- 位置交換(入れ替え)の命令は最初は無視し、まず左右反転・上下反転の命令を処理して反転されていない選択肢を除外してから、最後に位置交換の命令を行うと解きやすい。
- 1問あたり約25秒(20秒前後)で判断する必要があり、丁寧に解くだけでは時間が足りない。思考の切り替え回数を減らす効率化が重要。
- 優先順位と消去法を意識すると、複雑な問題も単純化して解答しやすい。

## 命令一覧と解法手順(学習者メモ、2026-08-23時点)

出題構成: 縦に並んだ箱の中に図形と、円またはひし形で表される命令記号が並ぶ。上の箱から順に命令を実行し、すべて実行した結果得られる図形群を5つの選択肢から1つ選ぶ。

命令の種類は以下の4分類・計10種類で固定されている。

1. **逆さま命令**: 上下逆さま／左右逆さま
2. **図形を消す命令**: 前の図形を消す／次の図形を消す
3. **取り消し命令**: 前の命令を取り消す／次の命令を取り消す
4. **入れ替え命令**: 前の図形と入れ替える／図形の順序を4・3・2・1にする／図形の順序を3・4・1・2にする／図形の順序を2・1・4・3にする

解法手順:
1. 図形に番号を振る(1・2・3・4のデフォルト順)
2. 取り消し命令を確認し、あれば対象となる命令の数字に丸をつける(その命令を無効化する印)
3. 逆さま命令を確認し、該当する数字に「左右→横棒」「上下→縦棒」をメモする
4. 入れ替え命令を確認し、数字を入れ替えてメモする
5. 最後にもう一度逆さま命令を確認し、反映してから解答する(逆さま命令の最終反映は一番最後に回す)

ポイント: 取り消し命令を最初に処理する。逆さま命令は優先度低め(位置が確定してから最後に反映する)。

## 演習からの追記(学習者メモ、2026-09-01時点)

- **注意点(誤解しやすいポイント)**: 「図形を消す命令」で図形自体が消えても、それより後にある命令は消えない。命令が無効化されるのは「取り消し命令」を受けたときだけ。「消す」＝図形が対象、「取り消し」＝命令が対象、という区別を混同しないこと。
- **メモの追加ルール**: 図形が消えたら、その番号に「×」を書いて管理する(取り消された命令には丸、消えた図形には×で区別する)。
- **実測の所要時間(例題ベース)**: 逆さま命令は1問あたり45秒〜1分30秒、図形を消す命令は15秒〜2分、取り消し命令は25秒〜1分程度かかっており、公称の目安(1問約25秒)より時間がかかる場合が多い。特に入れ替え(順序変更)命令の判断に時間がかかり、そこから他の命令の見落としにつながりやすい。
- **時間戦略の見直し**: 全問を丁寧に解くのは非現実的と判断し、命令表については**正答率40〜50%程度を狙う割り切り戦略**に切り替える。見た瞬間に「早く解けそう」と判断した問題を優先し、時間がかかりそう・難しそうと感じた問題は素早く飛ばす。

得意/不得意(2026-09-01時点):
- 得意: 図形を消す命令(選択肢の図形がかぶっているものが少なく、少ない判断材料で回答できた)
- 不得意: 入れ替え命令(順序変更)の判断に時間がかかる

## 模擬テストで確立した入れ替え命令の手順(2026-09-11時点)

模擬テスト(5分30秒・14問)を2周した結果、1周目(時間内)9/14(6割・時間内に解けなかった問題5問)、2周目(時間無制限)13/14(9割)。想定より時間に余裕があると感じ、目標を「正答率5〜6割」から「全問完答」へ引き上げた。間違えた問題の多くは入れ替え命令で、「前後の入れ替え→全体の入れ替え」という流れが未確立だったことが原因。

改訂した解法手順:
1. 入れ替え命令(前後)を処理する(取り消し命令を考慮しながら)
2. 全体の入れ替え命令を処理する
3. 選択肢を絞り、差異を逆さま命令から判断して解答する

暗記しておくと手順1を省略しやすいパターン(前後入れ替え命令が連続する場合):
- 2,3,4に前後入れ替え命令がつく: 1,2,3,4 → 2,3,4,1
- 2,3に前後入れ替え命令がつく: 1,2,3,4 → 2,3,1,4
- 3,4に前後入れ替え命令がつく: 1,2,3,4 → 1,3,4,2

また、命令は問題を重ねるごとに難易度が増していくため、序盤の問題を確実に解ききることが得点の安定につながる。

## 例題(簡易・自作)

命令表:
```
命令記号 A: 図形を時計回りに90度回転させる
命令記号 B: 図形の色を反転させる(白⇔黒)
命令記号 C: 図形を左右反転させる
```
問題: 初期図形は「白い右向き三角形」。命令 A → B の順に適用すると、最終的にどうなるか。

解答: 「時計回りに90度回転した(下向きになった)黒い三角形」
