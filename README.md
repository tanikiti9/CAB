## 2026-08-22

- **科目**: 法則性
- **学習内容**: 法則性のパターン分類の整理、演習問題での実践
- **感想**: 回転移動は難しかった。塗りは簡単。変形増減は回転がかかわっていることが多く、①〜⑤をまんべんなく考える必要がある。最初の5秒で気づけないものは20秒以上かかるので、パターンを見抜くには経験が必要だと感じた。
- **メモ**:
  - パターン分類: ①回転(45°・90°など角度が一定量ずつ増減) ②移動(四隅を順に移動、左右を交互に移動など) ③塗り(白→黒、白黒灰の繰り返しなど) ④変形(円→△など図形の種類が変わる、内側の図形が外側になる) ⑤増減(線の本数などが増減)
  - 判断のコツ: 線はまず角度(45°/90°、60°/120°)を疑う→規則がなければ本数を数える。色は白黒交互かどうかをまず確認。白黒の塗りにパターンがない場合は図形の数の増減と線の数に着目。直前の数字(点の数など)が次の図形のヒントになっている場合がある。
  - 得意: 塗り(色の変化)のパターンは判断が早い
  - 不得意: 回転・移動のパターン
  - 解く順の戦略: ①回転→②移動→③塗り→④変形→⑤増減の順に仮説をテンポよく当てはめる

## 2026-08-23

- **科目**: 命令表
- **学習内容**: 命令表の出題構成(縦に並んだ箱の中の図形＋命令記号)の理解、命令の種類(10種類)の整理、解法手順の確立
- **感想**: (特記なし。手順の整理が中心)
- **メモ**:
  - 命令は「逆さま」「消す」「取り消し」「入れ替え」の4分類・計10種類で固定
    - 逆さま命令: 上下逆さま／左右逆さま
    - 図形を消す命令: 前の図形を消す／次の図形を消す
    - 取り消し命令: 前の命令を取り消す／次の命令を取り消す
    - 入れ替え命令: 前の図形と入れ替える／図形の順序を4・3・2・1にする／3・4・1・2にする／2・1・4・3にする
  - 解く手順: ①番号を振る(1234のデフォルト順)→②取り消し命令を確認し対象に丸をつける→③逆さま命令を確認し該当番号に横棒(左右)/縦棒(上下)をメモ→④入れ替え命令を確認し番号を入れ替えてメモ→⑤最後にもう一度逆さま命令を反映して解答
  - ポイント: 取り消し命令を最初に処理する。逆さま命令は優先度低め(最終確定は最後)

## 2026-09-01

- **科目**: 命令表
- **学習内容**: 例題演習(逆さま命令・図形を消す命令・取り消し命令、各3問)、所要時間を計測
- **感想**: 命令表・問題・選択肢を効率よく見る必要があり、1問あたり平均25秒で解くのは現実的に厳しいと感じた。入れ替え命令の判断に時間がかかり、そこから他の命令のミスにつながった。→命令表は正答率40〜50%を目安に、早く解けそうな問題は解き、時間がかかりそう・分からなそうと感じたら飛ばす方針にする。
- **メモ**:
  - 所要時間(例題3問ずつ): 逆さま命令 45秒/1分30秒/45秒、図形を消す命令 15秒/27秒/2分、取り消し命令 40秒/25秒/1分
  - 誤解していた点: 「図形を消す命令」で図形が消えても、それより後にある命令自体は消えない(命令が消えるのは取り消し命令のときだけ)
  - 解法のコツ追加: 消えた図形の番号には×を置く
  - 得意: 図形を消す命令(選択肢の図形がかぶっているものが少なく、少ない判断材料で回答できた)、最後に逆さま命令を確認する意識ができた
  - 不得意: 入れ替え命令の判断に時間がかかる
