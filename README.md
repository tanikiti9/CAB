# CAB学習記録

## 目的

2026年10月末の本番試験（WebCAB）までに、CABテストの正答率8割以上を目指す。
学習後のレポート（日付・学習内容・課題など）をここに蓄積し、得意/不得意分野の分析に使う。

関連ファイル: [CAB_knowledge_base.md](./CAB_knowledge_base.md)（CABテストの試験形式・出題内容まとめ）

## 使い方

1. 参考書や模擬問題を解いたら、下記「レポートテンプレート」の項目に沿ってレポートを共有する。
2. 下記「学習ログ一覧」に1行、「詳細ログ」に1エントリとして追記していく。
3. ログが溜まったら科目別の傾向（得意/不得意）を分析し、対策に反映する。

## レポートテンプレート

レポートを送るときは、以下の項目をベースに書く（該当する項目だけでOK。無理に全部埋めなくてよい）。

```
日付:
科目: (四則演算 / 法則性 / 命令表 / 暗号 / 性格検査 / その他)
学習内容: どの範囲・何問くらい取り組んだか

気づいたパターン・ルール: 問題を解く中で見つけた規則性や分類(あれば)
解法のコツ・手順: 自分なりに確立した解き方の手順(あれば)

できた点・得意だと感じた部分:
苦手・つまずいた部分: なぜ詰まったか、どこで時間がかかったか

感想・気づき: 自由記述
次回への対策: 次に何を意識して取り組むか
```

- **現段階（演習・理解フェーズ）では正答率・スコアは不要**。パターンの理解や解法手順の確立を優先して記録する。
- 本番形式に近い演習を始めて数値化した結果(正答率・所要時間など)を計測したくなったら、その時点でテンプレートに項目を追加する。

### 2026-08-22

- **学習内容**: 法則性のパターン分類の整理、演習問題での実践
- **できた点・得意分野**: 塗り(色の変化)のパターンは判断が早い
- **課題・不得意分野**:
  - 回転・移動のパターンが難しい
  - 変形・増減は回転が絡むことが多く、①〜⑤の全パターンをまんべんなく検討する必要があり負荷が高い
  - 最初の5秒でパターンに気づけないと、そこから20秒以上かかってしまう → パターン認識の速度はまだ経験不足
- **メモ(パターン分類、詳細は[CAB_knowledge_base.md](./CAB_knowledge_base.md#法則性のパターン分類学習者メモ) 参照)**:
  - 線はまず角度(45°/90°、60°/120°)を疑う → 角度に規則がなければ本数を数える
  - 色は白黒交互かどうかをまず確認
  - 白黒の塗りパターンがない場合は、図形の数の増減と線の数に着目
  - 直前の数字(点の数など)が次の図形のヒントになっている場合がある
- **次回への対策**: ①回転→②移動→③塗り→④変形→⑤増減の順に仮説をテンポよく当てはめるルーティンを作り、5秒以内の一次判断の精度を上げる練習をする

- **できた点・得意分野**: (記録なし)
- **課題・不得意分野**: (記録なし)
- **メモ(命令の種類・解法手順、詳細は[CAB_knowledge_base.md](./CAB_knowledge_base.md#命令表の命令一覧と解法手順学習者メモ) 参照)**:
  - 命令は「逆さま」「消す」「取り消し」「入れ替え」の4分類・計10種類で固定
  - 解く手順: ①番号を振る(1234のデフォルト順) → ②取り消し命令を確認し対象に丸をつける → ③逆さま命令を確認し該当番号に横棒(左右)/縦棒(上下)をメモ → ④入れ替え命令を確認し番号を入れ替えてメモ → ⑤最後にもう一度逆さま命令を反映して解答
  - ポイント: 取り消し命令を最初に処理する。逆さま命令は優先度低め(最終確定は最後)
- **次回への対策**: この手順で実際の演習問題を解き、手順の精度とスピードに慣れる
